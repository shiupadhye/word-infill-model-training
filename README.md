# word-infill-model-training
Code for training infill-based GPT-2 
Adapted from the fill-in-the-middle approach proposed for code-infilling by [Bavarian et al. (2022)][https://arxiv.org/pdf/2207.14255]

More details about the current implementation can be found at: [Upadhye \& Futrell (2025)] [https://arxiv.org/pdf/2511.07752]

Existing pre-trained GPT-2 models can be found on Hugginface:

Trained on wikitext: https://huggingface.co/shiupadhye/gpt2-small-infill-adapted-wikitext

Trained on CANDOR (speech): https://huggingface.co/shiupadhye/gpt2-small-infill-adapted-candor

# word-infill-model-training
Code for training infill-based GPT-2 
Adapted from the approach proposed by [Bavarian et al. (2022)][https://arxiv.org/pdf/2207.14255]

Existing pre-trained GPT-2 models can be found on Hugginface

Training on wikitext: https://huggingface.co/shiupadhye/gpt2-small-infill-adapted-wikitext

Trained on CANDOR (speech): https://huggingface.co/shiupadhye/gpt2-small-infill-adapted-candor
